# Портреты сотрудников для /contacts

Карточка показывает инициалы, пока файла нет, и подхватывает фотографию сразу
после того, как файл появился здесь. Менять шаблон или код не нужно.

## Имена файлов

Имя берётся из поля `photo` в `$staffMembers` (см. `$contactsSeedProvider` в
`routes/web.php`):

| Сотрудник                        | Файл                        |
|----------------------------------|-----------------------------|
| Панкей Ж.                        | `pankey-zh.jpg`             |
| Корпешова Эльмира Мауткановна    | `korpeshova-elmira.jpg`     |
| Сайлаубек Айман Бастарбекқызы    | `sailaubek-aiman.jpg`       |

## Требования к файлу

- Формат: JPEG (`.jpg`). Если нужен другой — поправьте расширение в поле `photo`.
- Кадр: вертикальный, пропорция 4:5, не меньше 480×600 px (карточка выводит фото
  шириной ~260 px, запас нужен для экранов с высокой плотностью пикселей).
- Другая пропорция вёрстку не сломает: фото обрезается по рамке 4:5 с привязкой к
  верхней части кадра, чтобы в кадре оказалось лицо, а не подбородок.
- На телефоне карточка одноколоночная и пропорция переключается на 4:3 — это тот
  же файл, дополнительной версии не нужно.
- Вес: желательно до 150 КБ.

## Добавить ещё сотрудника

Допишите элемент в `$staffMembers` в `routes/web.php` — там задаются ФИО,
инициалы для заглушки, имя файла и должность на трёх языках. Сетка карточек
перестроится сама.
